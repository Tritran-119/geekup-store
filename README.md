# GeekUp Store

A containerized e-commerce application built with React (Vite), managed via Docker & Docker Compose, and powered by Mockoon CLI for API mocking.

---

## Prerequisites

* **Docker Desktop** (Installed & running)
* **Git**
* **Node.js** (`>= 20.x` - *only required for local development without Docker*)

---

## Setup & Getting Started

### Option 1: Docker Compose (Recommended)

1. **Clone the repository and enter the project folder:**
   git clone <YOUR_REPO_URL>
   cd geekup-store

2. **Build and start all containers (Frontend & Mock API):**
docker compose up --build -d

3. **Access the application:**
* Frontend Application: http://localhost
* Mock API (Direct): http://localhost:3001

4. **Stop the containers when done:**
docker compose down


### Option 2: Local Development (Hot Reloading)
1. **Start only the Mock API container:**
docker compose up mock-api -d

2. **Install dependencies and start Vite dev server:**
npm install
npm run dev

3. **Access the app:**
Open the local URL generated by Vite in your terminal (usually http://localhost:5173).
